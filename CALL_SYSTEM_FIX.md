# Исправление проблем с системой звонков

## Описание проблем

В системе звонков Zcord были обнаружены критические проблемы:

1. **Автоматическое присоединение к звонкам**: пользователи автоматически присоединялись к звонкам при входе в чат без явного подтверждения.
2. **Циклы присоединения/выхода**: возникал цикл присоединения и выхода из звонков.
3. **Зависание на этапе "Подключение..."**: звонки могли зависать на этапе подключения без перехода в состояние "connected".
4. **Неполная очистка ресурсов**: ресурсы WebRTC не всегда корректно очищались при завершении звонка.
5. **Ошибка SQL при выходе из звонка**: возникала ошибка `converting NULL to int is unsupported` при попытке выйти из несуществующего звонка.

## Внесенные изменения

### 1. Компонент ChatZone.jsx

- **ПОЛНОСТЬЮ ОТКЛЮЧЕНО автоматическое присоединение к звонкам** - теперь пользователь присоединяется к звонку ТОЛЬКО при явном нажатии на кнопку звонка
- Добавлен `lastCallEndTimeRef` для отслеживания времени последнего завершения звонка
- Улучшена функция `handleStartCall`, чтобы она также учитывала время последнего завершения звонка

```jsx
// Добавлен ref для отслеживания времени последнего завершения звонка
const lastCallEndTimeRef = useRef(0);

// Проверка наличия активного звонка, но БЕЗ автоматического присоединения
const checkActiveCall = async () => {
  if (data?.id && wsConnected && !callState.isCallActive) {
    try {
      console.log("Checking for active call in chat:", data.id);
      const activeCall = await webrtcService.checkActiveCall(data.id);

      // Мы только проверяем наличие активного звонка, но НЕ присоединяемся к нему автоматически
      if (activeCall) {
        console.log("Found active call:", activeCall);
        console.log(
          "NOT auto-joining call - user must click call button explicitly"
        );
      }
    } catch (error) {
      console.error("Error checking for active call:", error);
    }
  }
};

// Проверка в handleStartCall
if (recentlyEndedCall) {
  console.log("Call recently ended, preventing immediate restart");
  return;
}
```

### 2. Компонент VideoCall.jsx

- Добавлен `callEndTimeRef` для отслеживания времени завершения звонка
- Улучшена функция `handleEndCall` для более тщательной очистки ресурсов
- Добавлена проверка недавно завершенного звонка в useEffect, инициализирующем звонок
- Улучшена обработка состояния "ended" в callState

```jsx
// Добавлен ref для отслеживания времени завершения звонка
const callEndTimeRef = useRef(0);

// Проверка в useEffect
const timeSinceLastCallEnd = now - callEndTimeRef.current;
const recentlyEndedCall = timeSinceLastCallEnd < 5000; // 5 секунд

// Обновление времени завершения звонка в handleEndCall
callEndTimeRef.current = Date.now();

// Более тщательная очистка ресурсов
Object.values(remoteStreamsRef.current).forEach((stream) => {
  if (stream && stream.getTracks) {
    stream.getTracks().forEach((track) => track.stop());
  }
});
remoteStreamsRef.current = {};
remoteVideosRef.current = {};
```

### 3. Сервис WebRTC (webrtc.js)

- Добавлены переменные `lastCallEndTime` и `currentChatId` для отслеживания времени и чата последнего звонка
- Добавлен метод `resetCallbacks` для сброса всех колбэков при завершении звонка
- Улучшены методы `joinCall`, `leaveCall` и `checkActiveCall` для предотвращения повторного присоединения к недавно завершенному звонку

```js
// Добавлены переменные для отслеживания
this.lastCallEndTime = 0;
this.currentChatId = null;

// Проверка в методах
const timeSinceLastCallEnd = now - this.lastCallEndTime;
const recentlyEndedCall = timeSinceLastCallEnd < 5000; // 5 секунд
const isSameChatAsLastCall = chatId === this.currentChatId;

// Обновление времени завершения звонка
this.lastCallEndTime = Date.now();

// Метод для сброса колбэков
resetCallbacks() {
  // Сброс всех колбэков, кроме onCallError
}
```

### 4. Исправление SQL-функции leave_call

- Исправлена функция `leave_call` для корректной обработки случая, когда звонок не найден
- Теперь функция возвращает 0 вместо NULL, что предотвращает ошибку `converting NULL to int is unsupported`

```sql
-- Если нет активного звонка, возвращаем 0 вместо NULL
IF v_call_id IS NULL THEN
    RETURN QUERY SELECT 0::INTEGER, 0::INTEGER;
    RETURN;
END IF;
```

## Инструкции по тестированию

1. Запустите скрипт тестирования для проверки наличия всех необходимых изменений:

```bash
./test_call_system.sh
```

2. Запустите приложение и выполните следующие шаги:

   a. Войдите в чат и начните звонок, нажав на кнопку вызова
   b. Завершите звонок, нажав на кнопку завершения
   c. Сразу попробуйте начать новый звонок, нажав на кнопку вызова
   d. Убедитесь, что новый звонок не начинается автоматически
   e. Подождите 5 секунд и попробуйте начать звонок снова
   f. Убедитесь, что теперь звонок начинается нормально

3. Проверьте сценарий автоматического присоединения:

   a. Откройте два браузера и войдите в один и тот же чат с разных аккаунтов
   b. В первом браузере начните звонок
   c. Во втором браузере убедитесь, что вы не присоединяетесь к звонку автоматически
   d. Нажмите на кнопку вызова во втором браузере, чтобы присоединиться к звонку
   e. Завершите звонок в обоих браузерах
   f. Убедитесь, что цикл присоединения/выхода не возникает

## Дополнительные замечания

- Время ожидания между звонками (5 секунд) можно настроить в зависимости от требований пользователей
- Теперь пользователь присоединяется к звонку ТОЛЬКО при явном нажатии на кнопку звонка, что полностью решает проблему автоматического присоединения
- Добавлены таймауты для автоматического перехода в состояние "connected" (3 секунды) и автоматического завершения звонка при отсутствии соединения (15 секунд)
- Улучшена обработка ошибок и очистка ресурсов при завершении звонка
- Добавлена дополнительная защита от зависания в промежуточных состояниях
- Исправлена ошибка SQL при выходе из звонка, когда звонок не найден
- В будущих версиях можно добавить настройку для автоматического присоединения к звонкам (отключено по умолчанию) с явным подтверждением пользователя
